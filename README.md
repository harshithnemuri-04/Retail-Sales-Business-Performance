# Retail Sales & Business Performance Dashboard
## Project Overview
This project focuses on analyzing retail sales data using Microsoft Power BI.
The dashboard provides insights into sales performance, profit, orders, regional sales, monthly trends, and product category performance.
## Tools & Technologies
- Microsoft Power BI
- Microsoft Excel
- Data Cleaning
- Data Visualization
- Data Analytics
## Dashboard KPIs
- Total Sales: 2.30M
- Total Profit: 286.40K
- Total Orders: 5.009K
- Profit Margin: 12.47%
## Key Dashboard Features
1. Monthly Sales Trend
2. Sales by Region
3. Top 10 Products by Sales
4. Profit by Category
5. Interactive Region Filters
## Business Insights
- West region has the highest sales.
- East region is the second-highest sales contributor.
- Technology contributes the highest category profit.
- Monthly sales trends help identify business performance over time.
- Top 10 products highlight the major sales contributors.

- Dataset: Excel (.xlsx) file
